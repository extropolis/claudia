# Task Completion & Learning Extraction

The user has indicated the current task is complete. You must now perform a thorough self-evaluation and extract any learnings that could help in future tasks.

## CRITICAL: Storage Location

**ALL learnings MUST be saved to the CURRENT PROJECT directory, NOT to ~/.claude/**

Before doing anything else, determine the project directory. The working directory is the project root.
Use the current working directory for all file operations - save to:
- `.claude/skill-meta/` (relative to project root)
- `.claude/skills/` (relative to project root)

**NEVER save to ~/.claude/skill-meta or ~/.claude/skills**

## Step 1: Self-Evaluation

Rate your performance on this task across these dimensions (1-10 scale):

1. **Correctness**: Did the solution work? Were there bugs or errors?
2. **Efficiency**: Did you solve it in a reasonable number of steps? Did you avoid unnecessary work?
3. **Instruction Following**: Did you follow the user's requirements accurately?
4. **Code Quality**: Is the code clean, maintainable, and following best practices?
5. **Communication**: Did you explain your work clearly?

User override (if provided): $ARGUMENTS

## Step 2: Identify Mistakes & Learnings

Reflect on:
- What mistakes did you make during this task?
- What did you learn about THIS SPECIFIC PROJECT that would help in future tasks?
- What patterns, conventions, or gotchas did you discover?
- What files, directories, or tools are important to know about?

## Step 3: Categorize the Task

Identify relevant tags for this task (e.g., react, python, testing, debugging, refactoring, api, database, authentication, etc.)

## Step 4: Setup Project & Generate Structured Output

First, ensure the project has the required directories and files:

```bash
mkdir -p .claude/skill-meta .claude/skills
```

Create registry if it doesn't exist:
```bash
if [ ! -f .claude/skill-meta/registry.json ]; then
  echo '{"skills":[],"global_stats":{"total_ratings":0,"avg_score_trend":[],"most_improved_skill":null}}' > .claude/skill-meta/registry.json
fi
cat .claude/skill-meta/registry.json
```

**Update CLAUDE.md with skill references** - After creating/updating a skill file, ensure CLAUDE.md lists all skills so future sessions know what's available.

If CLAUDE.md doesn't exist, create it. If it exists, update the learnings section.

The learnings section should look like:
```markdown
## Learned Skills

**Read these before starting related tasks:**

- `.claude/skills/<skill-name>.md` - <description> (tags: tag1, tag2, ...)
```

List ALL skills from the registry with their file path, description, and tags.

Then create a JSON evaluation with your assessment:

```json
{
  "timestamp": "<ISO timestamp>",
  "overall_score": <1-10>,
  "dimensions": {
    "correctness": <1-10>,
    "efficiency": <1-10>,
    "instructions": <1-10>,
    "code_quality": <1-10>,
    "communication": <1-10>
  },
  "tags": ["<tag1>", "<tag2>", ...],
  "task_summary": "<brief description of what was accomplished>",
  "mistakes": [
    "<mistake 1>",
    "<mistake 2>"
  ],
  "learnings": [
    {
      "trigger": "<when this learning should be applied>",
      "insight": "<specific, actionable insight about THIS project>",
      "confidence": <0.0-1.0>
    }
  ],
  "save_worthy": <true if score < 7 and learnings exist, or if learnings are particularly valuable>,
  "user_feedback": "<any feedback from $ARGUMENTS>"
}
```

Save this evaluation to the project's conversation log (use relative path):
```bash
echo '<your-json-here>' >> .claude/skill-meta/conversation-log.jsonl
```

## Step 5: Create or Update Skill Files

If `save_worthy` is true:

1. **Check for existing matching skill**: Look in the registry for skills with overlapping tags
2. **If match found**: Read the existing skill file and UPDATE it with new learnings (merge, don't replace)
3. **If no match**: CREATE a new skill file

### Skill File Format

Create/update skill files at `.claude/skills/<skill-name>.md` (relative to project root):

```markdown
---
name: <kebab-case-name>
description: <What this skill covers and when to use it>
---

# <Title>

## Context
<Brief description of what area of the project this covers>

## Key Patterns
- <Pattern 1>
- <Pattern 2>

## Important Files & Locations
- `path/to/important/file` - <description>

## Conventions
- <Convention 1>
- <Convention 2>

## Gotchas & Learned the Hard Way
- <Gotcha 1>
- <Gotcha 2>

---
_Auto-generated by /learn | Confidence: <avg confidence> | Last updated: <date>_
_Source conversations: <count> | Version: <version>_
```

## Step 6: Update Registry

After creating/updating a skill file, update `.claude/skill-meta/registry.json` (relative to project root):

For new skills, add to the `skills` array:
```json
{
  "id": "<kebab-case-id>",
  "file": ".claude/skills/<name>.md",
  "tags": ["<tag1>", "<tag2>"],
  "confidence": <avg of learning confidences>,
  "created": "<ISO date>",
  "last_updated": "<ISO date>",
  "version": 1,
  "source_conversations": 1,
  "times_in_context": 0,
  "avg_score_before": <overall_score>,
  "avg_score_after": null
}
```

For existing skills, increment `version`, `source_conversations`, update `last_updated`, and recalculate `confidence`.

Also update `global_stats.total_ratings` and append to `avg_score_trend`.
