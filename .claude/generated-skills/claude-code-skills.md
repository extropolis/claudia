# Claude Code Skills

## Context
Claude Code supports custom skills (formerly slash commands) that extend Claude's capabilities. Skills are markdown files that define specialized instructions.

## Key Patterns
- Skills live in `.claude/skills/<skill-name>/SKILL.md`
- Legacy commands in `.claude/commands/` still work
- Skills use YAML frontmatter for configuration
- `$ARGUMENTS` substitution for dynamic input

## Important Files & Locations
- `.claude/skills/` - Project-level skills directory
- `~/.claude/skills/` - Personal skills (across all projects)
- `.claude/skill-meta/` - Skill management metadata

## Conventions
- Use kebab-case for skill directory names
- SKILL.md is required as the entrypoint
- Include `name` and `description` in frontmatter
- Description helps Claude decide when to auto-invoke

## Skill File Structure
```yaml
---
name: my-skill
description: What this skill does
allowed-tools: Read, Grep, Bash
---

# Instructions in markdown

$ARGUMENTS contains any passed arguments
```

## Gotchas & Learned the Hard Way
- Skills work through SAP AI Core proxy - they're just context instructions, not API features
- Skills can be auto-invoked by Claude or manually with /skill-name
- Use `disable-model-invocation: true` to prevent auto-invocation
- The `context: fork` option runs skills in a subagent
